# Intervals.icu MCP (Home Assistant app)

Runs the [Intervals.icu MCP server](https://github.com/bjorngadde/intervals-icu-mcp) as a remote
MCP endpoint for Claude custom connectors, authenticated by Intervals.icu OAuth or by a secret URL.
Put it behind the [Caddy app](../caddy/). See [DOCS.md](DOCS.md) for setup.
